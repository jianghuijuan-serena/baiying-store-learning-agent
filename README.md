# 门店培训 Agent · GitHub 源码版

本项目是可在本机运行的员工培训工作台。管理员维护知识库、审核题目、发布学习／考试／对练任务；学员阅读资料、答题、参加话术对练、查看成绩与逐轮复盘。

## 本机启动

1. 安装 Node.js 24 或更新版本。
2. Windows 双击 `开始使用.cmd`，或在本目录执行 `node server.mjs`。
3. 浏览器打开 `http://127.0.0.1:4180/`。服务只监听本机。
4. 首次启动自动创建空数据库和演示账号：

| 身份 | 账号 | 演示密码 |
| --- | --- | --- |
| 管理员 | `admin` | `DemoAdmin!2026` |
| 华东学员 | `east01` | `DemoLearner!2026` |
| 华南学员 | `south01` | `DemoLearner!2026` |

这些固定账号仅供本机演示。请勿直接把此版本开放到局域网或互联网；正式部署前应增加账号管理、改密、持久会话、访问控制和备份。

## 演示流程

管理员登录后，到“模型设置”填入兼容 OpenAI API 的服务地址、模型名称及自己的 API Key，先测试连接再保存。接着在“知识库”上传资料、检查切片和重复内容，在“题库审核”审核候选题，再发布学习、考试或对练任务。学员登录后从首页任务进入对应内容，在对练页查看逐轮点评和成绩。

AI 处理和对练需要管理员配置模型；配置保存在该设备的 `data/` 中，学员无需单独填写 Key。知识库搜索只检索系统已上传资料。上传资料若调用模型，会发送资料到管理员配置的服务，请先确认资料使用权限。

## 源码版与单机演示包

此 GitHub 源码版**不含**内部知识库、题库、学员数据、模型 Key 或预置任务，首次进入应由管理员自行上传和发布。此前的单机演示包包含真实培训资料，只适合在获授权的范围内私下交付，不应作为公开仓库附件上传。

若要在另一台 Windows 电脑上免安装 Node 演示，可单独构建带 Node 运行时的私下演示包。请先检查其中的培训资料与授权范围。模型 Key 不随包交付，每台独立设备由管理员单独配置。

## 上传 GitHub

建议先创建**私有仓库**，将本目录内容作为仓库根目录上传。确认品牌素材和代码的对外发布权限后，再考虑公开。不要上传运行后生成的 `data/`、个人资料、测试日志或私下演示包；`.gitignore` 已排除常见运行数据，但提交前仍应检查文件清单。

## 依赖说明

项目后端只依赖 Node.js 标准库。PDF、DOCX、XLSX 等文件解析需要目标设备安装 Python 及 `parse_document.py` 使用的解析依赖。TXT、Markdown 可直接使用。拓店专项的外部 Agent 需单独提供其项目路径；通用知识学习与对练不依赖该外部项目。
